# 🛡️ Memory Guardian
### Remember. Stay Safe. Stay Connected.

**Memory Guardian** is an IoT-based smart wearable and mobile application designed to support individuals experiencing memory-related difficulties, including people living with dementia. It aims to improve personal safety, encourage independence, and help caregivers stay connected through an integrated hardware and software solution.

## 🎯 Problem Statement
People experiencing memory-related difficulties may face challenges with daily routines, remembering important activities, and staying safe when away from familiar surroundings. Caregivers also need a reliable way to stay informed about their well-being and safety.

## 💡 Our Solution
Memory Guardian combines a smart wearable pendant with a companion mobile application and caregiver dashboard to provide safety assistance, routine management, and activity monitoring.

## ✨ Key Features

- **GPS Location Tracking:** Helps caregivers view the user's latest available location.
- **Emergency SOS:** Sends emergency alerts to caregivers when the SOS button is pressed.
- **Fall Detection:** Experimental motion-based detection using an accelerometer and gyroscope.
- **Medicine Reminders:** Helps users follow their scheduled medication routines.
- **Daily Routine Management:** Reminders for meals, water intake, walks, and other activities.
- **QR-Based Activity Tracking:** Records activity scans and user-confirmed activities.
- **Memory Support:** Familiar faces, important memories, and cognitive engagement games.
- **Caregiver Dashboard:** Provides access to alerts, activity records, reminders, and location information.

## 🔧 Hardware Components

- ESP32 Development Board
- NEO-6M GPS Module
- MPU6050 Accelerometer and Gyroscope
- TP4056 Charging Module
- 3.7V Li-Po Battery
- Buzzer
- Push Buttons and Slide Switch

## 💻 Technology Stack

- **Embedded Systems:** ESP32, Arduino IDE, C/C++
- **Mobile Application:** Under development
- **Backend & Database:** To be finalized
- **Connectivity:** Wi-Fi / Bluetooth
- **Location Services:** GPS

Currently under development as a college hackathon prototype. Hardware integration, embedded programming, mobile application development, and system integration are ongoing.

## ⚠️ Disclaimer

Memory Guardian is a supportive safety and routine-management prototype. It is not a medical device and does not diagnose, prevent, or treat dementia or any other medical condition.

## 👥 Our Mission

To make everyday life safer, more manageable, and more connected for individuals experiencing memory-related difficulties and the people who care for them.
